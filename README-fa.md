# اپلیکیشن اندروید Joyit

این پروژه یک اپلیکیشن ساده‌ی Android با `WebView` است که وب‌سایت `https://joyit.ir/` را داخل خود برنامه نمایش می‌دهد؛ مرورگر جداگانه‌ای باز نمی‌کند.

## امکانات

- نمایش تمام‌صفحه‌ی سایت Joyit
- پشتیبانی از JavaScript، Local Storage، کوکی‌ها و محتوای بازی‌های وب
- نمایش نوار پیشرفت هنگام بارگذاری
- صفحه‌ی خطای اتصال همراه با دکمه‌ی تلاش دوباره
- دکمه‌ی Back اندروید برای بازگشت در تاریخچه‌ی سایت
- لینک‌هایی که تب جدید باز می‌کنند، تا حد امکان در همان WebView باز می‌شوند
- شناسه‌ی برنامه: `ir.joyit.app`

## ساخت APK با GitHub Actions (بدون نصب Android Studio)

1. محتوای این پوشه را در یک مخزن GitHub قرار بده.
2. مخزن را باز کن و به بخش **Actions** برو.
3. گردش‌کار **Build Joyit APK** را انتخاب و روی **Run workflow** بزن.
4. پس از موفق شدن اجرا، از بخش **Artifacts** فایل `joyit-debug-apk` را دانلود کن.
5. فایل ZIP دانلودشده شامل `app-debug.apk` است؛ آن را روی گوشی اندرویدی نصب کن.

با هر push به شاخه‌ی `main` یا `master` نیز ساخت APK اجرا می‌شود.

## ساخت محلی

نیازمندی‌ها: JDK 17، Android SDK Platform 35، Android Build Tools 35.0.0 و Gradle 8.9.

در ریشه‌ی پروژه اجرا کن:

```bash
gradle assembleDebug
```

فایل خروجی در این مسیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## نکته

این APK پوسته‌ی وب‌سایت است؛ برای نمایش سایت و اجرای بازی‌های آنلاین، اتصال اینترنت لازم است. برای انتشار در Google Play باید APK را با کلید امضای انتشار خودت امضا کنی و تنظیمات انتشار را تکمیل کنی.
